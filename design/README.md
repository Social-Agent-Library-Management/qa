# 디자인 원본 (Claude Design 사본)

QA가 디자인 화면을 구현 화면과 같은 크기(1440×900)로 캡처해 비교하기 위한 읽기 전용 사본이다.

- 출처: Claude Design 프로젝트 `도서 관리 시스템 Design System` (`307f4357-35a5-463d-9674-9b2fefff09fa`)
- 가져온 날: 2026-10-16 (DesignSync `get_file`, 프로젝트에는 쓰지 않음)
- 범위: 화면 렌더링에 필요한 파일만 — `ui_kits/library/index.html`, `_ds_bundle.js`, `styles.css`, `tokens/*`
  (컴포넌트 문서·업로드 원본·엑셀은 제외)

화면 선택: `localStorage`의 `lib_ds_loggedIn=1`, `lib_ds_screen=<화면 ID>` (ID는 `ui_kits/library/README.md`).
디자인의 목업 데이터는 QA 시드와 다르므로 비교는 배치·구성·스타일 기준이다.
