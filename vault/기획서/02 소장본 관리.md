# 2.2 소장본 관리 (BookItem)

## [MVP] 소장본 등록
특정 도서(Book)에 연결해 보유 권수만큼 등록한다 (단건 수동 입력 + 엑셀 일괄 등록).

- **관리번호**: 관리자가 직접 입력, 형식 `(주제)-(번호)` (예: `문학-0001`), **고유성 검증 필수**.
- 엑셀 일괄 등록 시 관리번호는 엑셀의 `도서번호` 값을 그대로 쓰며 **비어 있으면 오류**(자동 생성하지 않음). `삽화2`처럼 하이픈이 없으면 `삽화-2`로 정규화 후 경고.
- **상태(status)**: 소장본 단위로 관리, 등록 시 기본값 `대출 가능`.

| 상태 | 설명 |
|---|---|
| `대출 가능` (AVAILABLE) | 대출 가능한 정상 소장본 |
| `대출 중` (ON_LOAN) | 현재 대출되어 있음 |
| `분실` (LOST) | 분실 처리된 소장본 |
| `폐기` (DISPOSED) | 훼손 등으로 폐기된 소장본 |

## [MVP] 소장본 상태 변경 (분실/폐기)
물리 삭제 대신 상태 전환으로 이력을 보존한다.

> ⚠️ 구현 노트: 서버는 `대출 중(ON_LOAN)` 여부를 검증하지 않는다(대출 중에도 바로 분실·폐기 가능). 단, **화면에서는 대출 중·연체 소장본의 분실/폐기 버튼을 비활성화**해 실수 처리를 막는다.

## [MVP] 소장본 검색·목록
도서명·저자, 관리번호로 검색한다. 도서 검색 화면에서 도서를 선택하면 해당 도서의 소장본 목록(관리번호·상태·대출자·반납예정일)이 함께 표시된다. 별도의 소장본 수정·삭제 API는 없다(상태 변경만 지원).
