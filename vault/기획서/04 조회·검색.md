# 2.4 조회 / 검색

- **[MVP] 도서 검색** — 전용 화면. 도서명·저자·출판사·ISBN으로 검색하고, 결과에 각 도서의 활성 소장본 수(`bookItemCount`)와 대출 가능 권수를 표시. **행을 선택하면 우측에 해당 도서의 소장본 리스트**가 열린다.
- **[MVP] 소장본 조회** — 도서명·저자, 관리번호로 검색 (소장본 등록 화면 및 도서 검색 화면에서 제공).
- **[MVP] 대출 내역 조회** — 도서명·대출자 이름·부서·상태(대출중/연체/반납완료) 다중 조건 검색·필터링.
  - 컬럼: 관리번호 · 도서명 · 대출자 · 부서 · 대여일 · 반납예정일 · **반납일** · 상태
  - **반납일**은 실제 반납된 건에만 표시하고, 미반납 건은 `—`로 표기한다.
- **[고도화] 검색 엔진 기반 전문 검색** — [[09 기술 요구사항]] 3.2 OpenSearch 참조.
