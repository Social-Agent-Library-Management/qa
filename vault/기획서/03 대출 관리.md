# 2.3 대출 관리 (Loan)

## [MVP] 대출 등록
- **대상**: 소장본(BookItem)의 **관리번호** 기준
- **필수 입력**: 관리번호, 대출자 이름, 부서명, 대여일
- **반납 예정일**: 대여일 기준 **+14일 자동 계산**
- **처리**: 등록 완료 시 해당 소장본 상태를 `대출 중`으로 변경
- **제약**: 이미 `대출 중`(또는 분실·폐기)인 소장본은 중복 대출 불가
- **[MVP] 대출자 이메일(선택)** — 필드는 저장되지만 이를 이용한 알림 발송([[06 알림]])은 아직 미구현

## [MVP] 반납 처리
- **처리**: 실제 반납일 기록 + 해당 소장본 상태를 `대출 중` → `대출 가능`으로 변경
- **제약**: `대출 중` 상태의 소장본만 반납 가능
