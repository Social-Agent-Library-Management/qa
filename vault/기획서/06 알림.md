# 2.6 알림 (Notification) — [고도화], 구현 상태: 미착수

- **[고도화] 반납 임박 알림** — 반납 예정일 **D-1**에 도달한 대출 건 추출·발송
- **[고도화] 연체 알림** — 연체 발생 건에 대한 알림 발송
- **발송 채널**: 이메일 (대출자 이메일 우선, 없으면 관리자 이메일)
- **발송 방식**: 매일 지정 시각 자동 실행

현재 코드베이스에는 Spring Batch·메일 발송·스케줄러 의존성이 없다. 대출자 이메일(`borrowerEmail`)은 저장만 되고 발송 로직은 없다.

## 3.1 배치·스케줄링 (설계만, 미착수)
- 목적: 매일 지정 시각에 반납 임박(D-1)·연체 도서를 조회해 알림 발송 자동화
- 전략: Spring Batch **Chunk 지향 처리** — 데이터가 늘어도 Paging/Chunk 단위로 나눠 DB 커넥션과 메모리를 효율적으로 사용(OOM 방지)

> QA 판정 참고: 알림 관련 화면·동작은 **존재하지 않는 것이 정상**이다.
