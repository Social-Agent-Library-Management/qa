# 2.7 엑셀 일괄 등록 / 내보내기 (Excel I/O) — [MVP]

기존 자료(「도서정리목록」 엑셀: 13개 시트 = 분류, 컬럼 `도서번호 · 도서명 · 출판사명 · 저자명`, 약 4,838행)를 그대로 적재하고 다시 뽑을 수 있게 한다.

## 2.7.1 일괄 등록 — 3단계
1. **파일 업로드 · 시트 선택** — 파일 1개(.xlsx/.xls, 최대 20MB, 첫 행은 머리글)를 올리면 시트 목록과 각 행수를 보여주고 **등록할 시트를 선택**한다. 컬럼 인식 결과(`도서번호 → 소장본 관리번호`, `도서명·출판사명·저자명 → 도서 서지`)를 함께 표시.
2. **검증 및 수정** — 검증 행 / 신규 도서 / 소장본 추가 / 오류·경고 건수를 요약하고, 기본은 **오류·경고 행만** 표시(전체 보기 토글). 오류 행은 셀이 인라인 입력으로 바뀌어 그 자리에서 수정하거나 **건너뛰기**할 수 있고, **오류가 남아 있으면 등록 버튼이 잠긴다**.
3. **등록 완료** — 등록 도서 / 등록 소장본 / 건너뛴 행 리포트, 리포트 다운로드, 도서 검색 화면으로 이동.

### 검증 규칙
| 판정 | 조건 | 처리 |
|---|---|---|
| 오류 | 도서번호 누락, 파일 내 도서번호 중복, 도서명 누락 | 등록 제외(수정 또는 건너뛰기 필요) |
| 경고 | 기존 도서와 동일(복본), 관리번호 형식 불일치, 저자명 공백 | 정규화·보정 후 등록 |
| 정상 | 신규 도서 + 소장본 1권 | 그대로 등록 |

- 등록되는 소장본의 초기 상태는 모두 `대출 가능`.
- ISBN·분류(시트명)는 엑셀에 없으므로 **저장하지 않는다**.

## 2.7.2 데이터 내보내기
- **시트 구성**: `도서` / `소장본` / `대여` 세 시트 (필요한 시트만 선택 가능)
  - 도서: 도서명 · 저자 · 출판사 · ISBN · 소장본 수 · 등록일
  - 소장본: 관리번호 · 도서명 · 상태 · 등록일 · 최근 대출일
  - 대여: 관리번호 · 도서명 · 대출자 · 부서 · 대여일 · 반납예정일 · 반납일 · 상태
- **옵션**: 대여 기간(시작~종료, 대여 시트에만 적용) · 분실·폐기 소장본 포함 여부 · 미반납 건만 내보내기
- **파일명**: `library_export_(YYYY-MM-DD).xlsx`, 최근 내보내기 이력(파일명 · 시트 · 생성 시각) 표시
