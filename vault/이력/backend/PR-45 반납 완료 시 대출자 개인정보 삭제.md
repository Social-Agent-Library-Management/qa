## 주의 사항 및 참고사항
- 사용 중인 DB의 경우 스키마 수동 반영 필요 (`ddl-auto: update`는 기존 컬럼의 NOT NULL을 해제하지 않아서 반납 API가 제약 위반)
    ```
    ALTER TABLE loan MODIFY COLUMN borrower_name VARCHAR(255) NULL;
    UPDATE loan SET borrower_name = NULL, borrower_email = NULL WHERE status = 'RETURNED';
    ```
- 반납 완료 건은 대출자 이름으로 조회·검색이 불가능해짐. 대출자 이름을 표시하던 화면 대응 필요
