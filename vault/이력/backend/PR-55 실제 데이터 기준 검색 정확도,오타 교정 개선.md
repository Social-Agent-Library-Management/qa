### 이슈 #54 실제 데이터 적용 후 검색 정확도·오타 교정 동작 이상
## 문제 상황(배경)
> 더미 데이터 기준으로 검증한 검색·오타 교정이 실제 도서 목록 건에서는 동작하지 않음
    (인수인계받은 도서 데이터의 띄어쓰기가 불규칙함)

## 해결 방안(구현 계획)
