# backend PR #51 fix(#50): 목록 조회 페이징 중복,누락 수정

## 증상·요구 (연결 이슈)
### 이슈 #50 목록 조회 페이징 중복,누락 발생
## 문제 상황(배경)
> 목록 조회 API 대부분이 단일 키로만 정렬하고 있어 정렬 키가 같은 행들의 순서가 보장 X

## 해결 방안(구현 계획)
- 모든 목록 조회 정렬에 2차 정렬 키 추가


## 변경 내용 (PR 본문)
## 연관 이슈
- 이 PR이 해결하는 이슈: #50

## 작업 사항
- 목록 조회 정렬에 2차 정렬 키 추가
  - 단일 키 정렬이라 정렬 키가 같은 행의 순서가 보장되지 않아 페이지를 넘길 때 같은 행이 중복으로 나오거나 일부 행이 조회되지 않던 문제 수정
      - `SearchLoansService` : `loanDate desc, id desc`
      - `SearchBookItemsService` : `createdAt desc, id desc`
      - `MysqlLikeBookSearchAdapter` / `MysqlFullTextBookSearchAdapter` : `createdAt desc, id desc`
      - `BookRepository.searchFullText` : `order by`에 `, t.id desc` 추가
      - `OpenSearchBookSearchAdapter` : 요청 본문 `sort` 배열에 `{ "bookId": "desc" }` 추가
