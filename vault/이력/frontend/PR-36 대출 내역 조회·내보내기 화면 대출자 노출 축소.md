## 증상·요구 (연결 이슈)
### 이슈 #35 fix: 대출 내역 조회·내보내기 화면 대출자 개인정보 노출 축소
## 문제 상황(배경)
개인정보 보호를 위해 두 관리자 화면에서 "대출자" 노출 범위를 줄여야 한다.

## 해결 방안(구현 계획)
1. 대출 내역 조회(LoanHistoryCard)
   - 테이블 "대출자" 컬럼 삭제 → 관리번호/도서명/부서/대여일/반납예정일/반납일/상태 7컬럼
   - 검색 대상에서 대출자 이름 제외 → 도서명·부서로만 검색
2. 내보내기 화면
   - LOANS(대여) 시트 컬럼 미리보기 목록에서 "대출자" 삭제

참고: 백엔드 GET /loans는 managementNumber 검색 파라미터를 지원하지 않아 관리번호 검색은 이번 범위에서 제외한다(사용자 확인).

이 이슈는 아직 main에 병합되지 않은 PR #28(feat/#27, 내보내기 화면 구현)에 의존한다 — 작업 브랜치는 feat/#27에서 분기한다.
