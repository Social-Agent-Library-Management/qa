### 이슈 #19 feat: 도서 등록 화면에 출판사 입력 및 출판사 소장본 수 조회 추가
## 구현 계획
- 도서 등록 폼(`BookRegisterForm`)에 출판사(publisher) 입력 필드 추가 (백엔드 `Book.publisher` non-blank 필수와 일치시켜 `required`)
- 출판사명 입력 시(디바운스) 해당 출판사의 기존 소장본 수를 조회해 보여주는 기능 추가
  - 백엔드에 출판사별 집계 전용 엔드포인트가 없어, `/books/search` 전체 순회 후 클라이언트에서 publisher 완전 일치 필터링 + `bookItemCount` 합산 방식으로 구현 (`ReturnListCard`/`LoanHistoryCard`의 클라이언트 필터링 컨벤션과 동일)
- 도서 목록 표(`BookListCard`)에 출판사·소장본 수 컬럼 추가 (Design `BookRegistrationScreen` 컬럼 구성과 일치시킴 — 현재 누락돼 있던 부분)
- `src/lib/api/books.ts`의 `Book`/`BookListItem`/`CreateBookInput` 타입에 `publisher`, `bookItemCount` 반영

디자인: Claude Design `ui_kits/library/index.html`의 `BookRegistrationScreen`
