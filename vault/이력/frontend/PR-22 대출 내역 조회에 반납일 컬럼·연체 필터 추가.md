# frontend PR #22 feat(#21): 대출 내역 조회에 반납일 컬럼·연체 필터 추가

## 증상·요구 (연결 이슈)
### 이슈 #21 feat: 대출 내역 조회에 반납일 컬럼·연체 필터 추가
## 배경
대출 내역 조회(#15) 구현 당시 백엔드 `/loans` 검색이 `ON_LOAN`/`RETURNED` 두 상태만 지원해 "연체" 필터를 넣지 못했다(`LoanHistoryCard` 주석 참고). 이후 백엔드에 `LoanSearchStatus.OVERDUE`가 추가되어 서버 필터가 가능해졌다.

## 요구사항
1. 대출 내역 표에 **반납일**(`returnedAt`) 컬럼 추가 — 반납 완료 건만 값 표시, 미반납은 빈 값/대시
2. 상태 필터에 **연체** 옵션 추가 — 서버 `GET /loans?status=OVERDUE` 사용(클라이언트 재필터링 금지)

## 참고
- 백엔드: `org.library.loan.controller.LoanController`, `SearchLoansService.LoanSearchStatus`(ON_LOAN/OVERDUE/RETURNED), `LoanSummary.returnedAt`
- 프론트: `src/components/library/loan-history-card.tsx`, `src/components/library/loan-table.ts`, `src/lib/api/loans.ts`
- 디자인: Claude Design `ui_kits/library/index.html`

## 작업 사항
- `GET /loans` 검색 파라미터용 `LoanSearchStatus`(ON_LOAN/OVERDUE/RETURNED) 타입 신설 — 백엔드가 이미 지원하는 3값 필터를 프론트에 반영
- 대출 내역 조회 표에 **반납일** 컬럼 추가: `LoanHistoryCard` 전용 `LOAN_HISTORY_COLUMNS`(8컬럼)를 신설해 대출 현황 화면(`LOAN_COLUMNS`, 7컬럼)과 분리 — 대출 현황은 `status=ON_LOAN` 고정이라 반납일이 구조적으로 항상 비어 있어 공유하지 않음(디자인도 두 화면 컬럼셋이 다름)
- 상태 필터에 **연체** 옵션 추가(전체/대출중/연체/반납완료) — 서버 `status=OVERDUE` 필터 사용, 클라이언트 재필터링 없음
- **연체 목록 화면(`/overdue`, `#17`) 제거** — 대출 내역 조회의 연체 필터로 완전히 흡수되는 중복 기능이라 기획에서 뺌. `OverdueListCard`, `GET /loans/overdue` API 레이어(`searchOverdueLoans`/`OverdueLoanSummary` 등), 사이드바 nav 항목, `IconOverdue` 함께 정리
- `src/components/README.md` 인벤토리·합성 관계를 위 변경에 맞춰 갱신(신규 컴포넌트 없음)
