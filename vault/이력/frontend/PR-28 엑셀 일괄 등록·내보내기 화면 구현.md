## 구현 계획
- `엑셀 일괄 등록` 화면(`POST /imports/excel`): 실제 파일 업로드(드래그앤드롭 + 파일 선택) → 성공(201)/오류(409, all-or-nothing) 결과 표시
- `내보내기` 화면(`POST /exports/excel`): 시트 선택(도서/소장본/대여) + 대여기간·옵션 → 엑셀 파일 다운로드
- 디자인: Claude Design `ui_kits/library/index.html`의 `ExcelImportScreen`/`DataExportScreen`
- 기존 `src/components` 재사용 컴포넌트(Card/Button/Input/DataTable/Toast/AppSidebar 등) 활용
- API 클라이언트: multipart 업로드, blob 다운로드, 409 정상 응답(all-or-nothing 거부) 처리를 위한 전용 fetch 추가 필요 (`src/lib/api/client.ts`가 현재 JSON 전용)
