## 설계

**훅은 받아적기만 하고 판단하지 않는다.** 집계는 오프라인 스크립트가 하므로 훅 버그가 하네스 실행을 깨뜨릴 수 없고, 로깅 이벤트는 전부 `async`라 실행 속도에 영향이 없다.

동기 실행되는 게이트는 2개뿐이다.

1. **커밋 트레일러 모델명 자동 교정** — 유일한 차단 지점. 실모델은 `SessionStart.model`(항상 있지는 않다)이 아니라 트랜스크립트의 `message.model`에서 읽는다.
2. **PR 생성 시 파이프라인 충실도 경고** — 차단하지 않는다. 머지 직전에 "이번 건은 QA를 안 거쳤다"를 알리는 것이 목적이다.

계측의 소비자는 에이전트가 아니라 **사람**이다. 과거 실행 요약을 `SessionStart`로 에이전트에 주입하는 안은 검토 후 채택하지 않았다 — 이미 있는 규칙("2회 반복이면 추출")도 안 지켜져 뒤늦은 `refactor`가 7건 났고, 데이터를 더 준다고 지켜지지 않으며 효과 측정도 불가능하기 때문이다.

## 개발 중 발견한 사고

게이트를 켠 직후 **게이트가 `git commit`이 아닌 Bash 호출까지 받아 heredoc 본문의 트레일러 문자열을 치환했다.** `settings.json`의 `if` 조건이 스코프를 걸지 못했고, 파일을 쓰는 명령의 본문이 커밋 메시지로 오인됐다.

훅 자신의 로그에 증거가 남아 잡았다:

```
TrailerCorrected | declared='Claude Opus 4.8'
TrailerCorrected | declared='{}'      ← 자리표시자를 모델명으로 치환
```

수정: `if` 조건을 믿지 않고 훅 안에서 실제 실행되는 첫 명령을 직접 확인한다(`leading_command()`). 이 시나리오 3개를 회귀 테스트로 고정했다.
