# 관리자 엑셀 일괄 등록 디자인 시안

Claude Design 프로토타입을 QA 캡처와 같은 1440×900로 렌더링한 화면이다.
목업 데이터는 QA 시드와 다르므로 구현 화면과는 **배치·구성·스타일**로만 비교한다(글자·숫자 값 차이는 결함이 아니다).

## 화면 구성 (본문 접근성 트리, 공통 사이드바 제외)
```yaml
- main:
  - button "도서 등록"
  - button "소장본 등록"
  - button "대출 내역 조회"
  - button "엑셀 일괄 등록"
  - button "내보내기"
  - text: 엑셀 일괄 등록 하나의 엑셀 파일로 도서와 소장본을 함께 등록합니다 엑셀 파일 파일을 끌어다 놓거나 아래에서 선택하세요 .xlsx · .xls · 최대 20MB · 첫 행은 머리글로 처리됩니다
  - button "bookList.xlsx 481 KB"
  - button "산림_입고분_수정전.xlsx 34 KB"
  - text: · 도서명 + 출판사 + 저자가 모두 같으면 동일 도서로 보고 소장본만 추가합니다 · 파일 형식이 다르거나(INVALID_FILE_TYPE), 읽을 수 없거나(UNREADABLE_FILE), 필수 컬럼이 없거나(REQUIRED_COLUMN_NOT_FOUND), 20MB를 초과하면(FILE_TOO_LARGE) 업로드가 즉시 거부됩니다
  - button "엑셀 파일 등록" [disabled]
```
